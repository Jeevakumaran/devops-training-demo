# DevOps Training - About This Project

## Project Purpose
This is a demo project created during our DevOps training program.
We use this to practice Git commands and understand version control.

## What is DevOps?
DevOps is a set of practices that combines software development (Dev)
and IT operations (Ops) to shorten the development lifecycle and
deliver high-quality software continuously.

## Key Concepts
- Continuous Integration (CI)
- Continuous Deployment (CD)
- Infrastructure as Code (IaC)
- Monitoring & Logging
- Collaboration & Communication
