# 📖 Glossary - DevOps Terms

| Term            | Meaning                                              |
|-----------------|------------------------------------------------------|
| **Git**         | A version control tool to track code changes         |
| **GitHub**      | A website to host Git repositories online            |
| **Repository**  | A project folder tracked by Git                      |
| **Commit**      | A saved snapshot of your changes                     |
| **Branch**      | A parallel copy of code for safe changes             |
| **Merge**       | Combining changes from one branch into another       |
| **Clone**       | Downloading a full copy of a repository              |
| **Push**        | Uploading your commits to GitHub                     |
| **Pull**        | Downloading latest changes from GitHub               |
| **Pull Request**| A request for the team to review your code           |
| **API**         | Application Programming Interface                    |
| **DNS**         | Domain Name System (internet phonebook)              |
| **HTTP/HTTPS**  | Protocol for web communication                       |
| **SSH**         | Secure Shell — encrypted remote access               |
| **CLI**         | Command Line Interface                               |
| **Linux**       | Free open-source operating system                    |
| **IP Address**  | Unique address for a device on the network           |
| **Port**        | A numbered door for network services                 |
| **Firewall**    | Security guard that controls network traffic         |
| **SDLC**        | Software Development Life Cycle                      |
